# Watering schedule

- **Bed A** (tomatoes): deep watering every second morning; daily above 28 °C.
- **Bed B** (beans, squash): twice a week, soil first, never the leaves.
- **Bed C** (lettuce): light watering every evening while seedlings are small.

Mulch Bed A once the soil is warm; it halves the watering.
